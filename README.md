# Dynasty Sim

Текстовый симулятор династии по мотивам режима авантюриста Crusader Kings 3. Вымышленный мир по законам нашего, около 1700 года. Сюжета нет: история складывается из случайностей и решений игрока, после смерти главы рода игра продолжается за наследника.

```
npm ci
npm run dev                             # игра в браузере
npm test                                # тесты
npm run validate                        # проверка контента
npm run sim -- --years 300 --seed 42    # прогон без интерфейса, хроника в out/
```
