# Тесты
- Точные числа проверяются на базовой фикстуре `tests/fixtures/base/*.yaml` (файл на модуль, `fixtureContent({...})` из `tests/fixtures/content.ts`, темп событий — `fixtureNarrator({...})`), а не на реальном контенте.
- У модуля свой файл тестов `tests/<модуль>.test.ts`. Тест-страж `tests/save.test.ts`: сохранение и загрузка после каждой команды 20-летнего прогона дают то же состояние.
- Детерминизм — сравнением хроник двух прогонов. «Золотых» снимков хроники нет.
- Тест не подгоняется под код: менять ожидание теста или коридор метрики можно только с причиной в описании PR.
