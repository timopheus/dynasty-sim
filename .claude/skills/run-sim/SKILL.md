# Прогон симуляции и сводка хроники

Аргументы: `$ARGUMENTS`. Первое число — сколько лет (по умолчанию 300), второе — seed (по умолчанию 1).

Ты работаешь в репозитории dynasty-sim. Отвечай по-русски. Ничего в репозитории не меняй.

## Шаги
1. Если нет `node_modules`, выполни `npm ci`.
2. Запусти `npm run sim -- --years <лет> --seed <seed>`. Сохрани вывод: в нём даты, число записей, событий, смертей, глав рода, путь к файлу хроники и нарушения инвариантов. Код возврата не 0 — это ошибка, покажи её полностью.
3. Прочитай файл хроники (путь из вывода). Это markdown: раздел `## Имя (годы)` на каждого главу рода, строки `- дата — текст`.
4. Посчитай:
   - главы рода: `grep '^## ' <файл>` — имена и годы жизни;
   - самые частые записи без имени персонажа:
     `grep '^- ' <файл> | sed 's/^- [^—]*— //' | sed -E 's/^[A-Z][a-z]+ [A-Z][a-z]+//' | sort | uniq -c | sort -rn | head -10`.
5. Найди аномалии: ошибки и нарушения из вывода; одна запись, занимающая больше четверти хроники; главы рода, прожившие меньше 20 или больше 90 лет; годы без единой записи; странные числа в итоговой строке (здоровье вне 0–100, огромные деньги).

## Ответ
```
Прогон: <лет> лет, seed <seed>, <дата начала> → <дата конца>. Нарушений: нет | <список>.
Главы рода: <N>. <Имя (годы)>, <Имя (годы)>, …
Записи: <всего>; события <N>, действия <N>, смерти <N>.
Чаще всего: <запись> — <раз>; … (топ-5)
Аномалии: <список или «не заметил»>.
Выдержки:
  <3–5 характерных строк хроники с датами>
Файл: <путь к хронике>
```
