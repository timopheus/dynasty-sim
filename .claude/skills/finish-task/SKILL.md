# Завершение задачи $ARGUMENTS

Иди по шагам. Шаг не прошёл — исправь и повтори, не перескакивай.

## 1. Проверки
```
npm run check
npm run sim -- --years 300 --seed 1
npm run sim -- --years 300 --seed 2
npm run build
```
Все без ошибок, в прогонах «Invariant violations: none». Последний критерий задачи (исполняемая проверка из ROADMAP) выполнен. Изменился интерфейс — пройди сценарий в браузере (Playwright, Chromium в `/opt/pw-browsers`), сохрани 2–3 скриншота.

## 2. Доки
- `docs/CHANGELOG.md`: запись сверху с датой, ID и что изменилось для игры.
- `docs/ROADMAP.md`: статус своей строки — «готово» со ссылкой на PR.
- STATUS, decisions-active и CLAUDE.md не правь: их ведёт ведущая сессия. Что ей перенести (решения, несрочные вопросы Тиму, новые команды) — разделами в описании PR.

## 3. Коммит и PR
- Коммит на английском, push в ветку задачи.
- PR `[ID] Название по-русски`, описание по-русски:
  - **Что сделано** — для Тима, языком игры;
  - **Как проверить** — команды; для интерфейса — скриншоты и «три шага, что проверить руками»;
  - **Решения** — новые решения задачи одной строкой каждое (ведущая сессия перенесёт в decisions-active);
  - **Что осталось** — заглушки и следующие шаги.
- Перед мержем влей свежий `origin/main` (merge, не rebase) и сведи конфликты, ничего чужого не теряя.

## 4. Ревью
Крупный PR (новая механика, сборочные файлы, формат сохранения) — субагент `reviewer`: передай ID, ветку, номер PR и одну-две фразы о цели. Мелкий PR (контент, правка, доки) — `/code-review`, а если его нет в сессии — тоже `reviewer`.
- «НУЖНЫ ПРАВКИ» — исправь, закоммить, проверь заново.
- Замечания «(необязательно)» — исправь, если дёшево и в рамках задачи; иначе перечисли в PR.

## 5. CI
Подпишись на события PR и закончи ход: CI сам разбудит сессию. Не жди в цикле. Упал CI — найди причину в логах, исправь, push.

## 6. Мерж
Когда CI зелёный и ревью одобрено: выведи PR из черновика, squash-мерж в main (заголовок — заголовок PR с номером). Без force-push и правок CI.

## 7. Отчёт Тиму
Три коротких блока: что сделано, что сломалось, что ждёт его решения. Ссылка на PR.
