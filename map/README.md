# Карта региона

Исходники карты из Azgaar's Fantasy Map Generator (D-025, D-026). Правятся только в Azgaar, руками не редактируются.

- `region.map` — сохранение Azgaar, открывается через Load. Источник правок.
- `region.json` — Export → JSON → full из того же состояния. Источник импорта (этап 5).
- `region.svg` — картинка для людей, в игру не идёт.

Как править и как сделать карту заново — `docs/map-guide.md`.

## scripts/
Скрипты, которыми сделана текущая карта (D-026). Они не часть игры и не запускаются в CI. Работают с локальной копией Azgaar 1.154.1 (`npx vite` в её исходниках, порт 5199) и Playwright с Chromium.
- `common.mjs` — открывает Azgaar с нашими настройками (D-024, D-026) и seed.
- `stage1.js` — культуры и базы имён, пересоздание бургов и провинций.
- `stage2.js` — передача земель, морские столицы, имена по культурам, провинции с центрами, державы, города, морские зоны.
- `export.mjs` — прогоняет оба этапа и сохраняет `region.map`, `region.json`, `region.svg`.
- `check.py` — сверка экспорта: провинции без центра, крошечные и рваные провинции, связность морских зон, столицы на берегу.

Для пролива на запад в копии Azgaar ослаблены западные горы шаблона Mediterranean (D-026).
