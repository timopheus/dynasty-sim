# Библиотека портретов (проба, 10.11.2026)

Готовые портреты среднего возраста, 48×60, фон #e8e4dc. Нарисованы Retro Diffusion (RD Fast, стиль `rd_fast__portrait`, палитра `docs/reference/portrait/palette-library12.png`), листами по 20–35 человек за $0,03. Код только режет листы, снимает фон клеток, ставит фигуру в рамку и отбраковывает.

- `portraits/` — 477 портретов: культура-пол-номер. `portraits.json` — культура, пол, исходный лист и клетка.
- `batch1/`, `batch2/`, `batch3/` — исходные листы и запросы (`*-prompt.txt`); `provenance.jsonl` — журнал каждой генерации (D-430).
- `library-overview.png` — по 12 портретов от каждой группы.
- Инструменты: `tools/portrait/cut_sheet.py` (нарезка по фону), `cut_grid.py` (по сетке), `normalize.py` (рамка 48×60, снятие фона клетки), `clones.py` (поиск похожих; в этом стиле ошибается, не используется).
