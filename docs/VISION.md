# Видение Dynasty Sim

Одна страница, ради чего игра. Пишется с Тимом (интервью ведущей сессии) и меняется только с его согласия. Каждая задача называет опору и целевую историю отсюда (D-430). Подробный дизайн — `docs/GDD.md`.

> Статус: **черновик**. Опоры перенесены из GDD §2. Обещания ощущений, «чего мы не делаем» и целевые истории заполняются на интервью с Тимом (неделя 1 новой модели).

## Игра в одной фразе
Текстовый симулятор династии по мотивам режима авантюриста CK3: ты ведёшь главу рода через рискованную жизнь, а после его смерти — наследника; из случайностей и твоих решений складывается хроника рода, которую интересно перечитать.

## Опоры (GDD §2, D-013)
Если идея противоречит опоре, меняется идея.
1. **История из системы, не из сценария.** Каждая заметная строка хроники — следствие состояния мира, случая и выбора игрока.
2. **Хрупкий взлёт.** Мир опасен, успех добывается рискованными выборами и легко теряется. У каждого выбора есть цена.
3. **Последствия живут дольше героя.** Деньги, долги, репутация, враги и обещания переходят наследнику, слава рода копится поколениями.
4. **Мир живёт без игрока.** Рядом с героем всё подробно, вдали — грубо, но мир не стоит на месте.
5. **Хроника — главный результат.** Всё важное становится строкой хроники, которую интересно перечитать.
