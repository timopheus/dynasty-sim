# Карта в Azgaar: как править и как сделать заново

Для Тима. Решения, на которых она держится: D-009 (масштаб), D-023 (державы), D-024 (настройки), D-025 (что экспортировать и где хранить), D-026 (текущая карта). Проверено по Azgaar 1.154.

Карта уже сделана: `map/region.map`, картинка — `map/region.svg`. Обычно нужен только раздел «Править карту». Остальные разделы — на случай, если карту захочется сделать заново.

## Править карту
1. Открыть https://azgaar.github.io/Fantasy-Map-Generator/ → **Load** → выбрать `region.map` (скачать из папки `map/` репозитория: файл → кнопка Download raw).
2. Поправить: имена, границы, группы бургов, морские зоны (см. ниже, что важно для импорта).
3. Сохранить и экспортировать три файла (раздел «Сохранить и экспортировать»).
4. Загрузить их в репозиторий (раздел «Передать файлы»).

Что важно для импорта (D-025, D-026):
- **Города** — бурги групп `capital` и `city`, их должно быть 15–25. Группа меняется в редакторе бурга.
- **Провинций** 40–60 (Tools → Provinces, счёт внизу).
- **Морские зоны** — зоны с типом `Sea` (Tools → Zones). Каждая вода у берега должна принадлежать какой-то зоне. Другие зоны (вторжения, эпидемии, которые Azgaar создаёт сам) лучше удалить.
- Большой ничейной земли быть не должно: отдайте её соседней державе кистью «Manually re-assign states» в редакторе держав.

## Сохранить и экспортировать
Все три файла — из одного и того же состояния карты, сразу друг за другом:
1. **Save → machine** — файл `.map`. Переименовать в `region.map`.
2. **Export → Export To JSON → full** — файл `.json`. Переименовать в `region.json`.
3. **Export → Download image → .svg** — переименовать в `region.svg`.

## Передать файлы в репозиторий
Через GitHub в браузере:
1. Открыть https://github.com/timopheus/dynasty-sim и выбрать ветку задачи (кнопка выбора ветки над списком файлов).
2. Зайти в папку `map`, нажать **Add file → Upload files** и перетащить три файла.
3. **Commit changes** прямо в ветку задачи (не в main).
4. Написать в чат сессии, что файлы загружены.

Лимит GitHub для загрузки через браузер — 25 МБ на файл; `region.json` весит около 8 МБ.

Можно и проще: прислать в чат скриншот и сказать, что поменять, — сессия сделает правку сама в своей копии Azgaar (так сделана текущая карта, D-026).

## Сделать карту заново
1. Меню (стрелка ◄ слева вверху) → вкладка **Options** → блок **Map settings**:

   | Настройка | Значение | Зачем |
   |---|---|---|
   | Map size | 1600 × 900 px | вытянутый регион |
   | Points number | 10K | рекомендованное значение |
   | Heightmap | Mediterranean | море посередине, суша вокруг |
   | Cultures set | European | европейские и турецкие имена |
   | Cultures number | 8 | большие державы, малые и общины |
   | States number | 7 | 4 большие + 3 малые |
   | Provinces ratio | 26 | около 50–60 провинций |
   | Size variety | 4 | большие и маленькие державы рядом |
   | Growth rate | 1.5 | почти без ничейной земли |
   | Burgs number | 120 | бургов нужно больше, чем провинций |
   | Religions number | 4 | разные веры для общин |

   У каждой изменённой настройки замок слева должен быть **закрыт**, иначе при новой карте значение выпадет случайно.
2. **Tools → Units**: Distance unit **Kilometer**, «1 map pixel» = **1.25** (регион около 2000 × 1100 км); «1 population point» = **500**, «Urbanization rate» = **4**.
3. **New Map** (F2), пока не выйдет море с проливом на запад. На сайте это редкость: шаблон Mediterranean ставит у западного края горы. Текущая карта сделана с ослабленными западными горами (D-026).
4. **Tools → Cultures**: базы имён — German (Хаверланд), French (Оренн), Ruthenian (Борея), Turkish (Измара), для малых держав и общин — по вкусу.
5. **Tools → Regenerate → Burgs**, затем **Regenerate → Provinces**: имена пересоздадутся по культурам.
6. **Tools → States**: переименовать четыре большие державы (имя, форма правления), столицы — в **Tools → Burgs** (Ostmere, Valmont, Novomor и Kostrograd, Sarayhan; GDD §6).
7. Проверить города, провинции и морские зоны (раздел «Править карту»), затем сохранить, экспортировать и передать файлы.
