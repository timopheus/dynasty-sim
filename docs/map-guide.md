# Карта в Azgaar: пошаговая инструкция

Для Тима. Решения, на которых она держится: D-009 (масштаб), D-023 (державы), D-024 (раскладка и настройки), D-025 (что экспортировать и где хранить). Проверено по Azgaar 1.154.

Цель: внутреннее море с проливом в океан на западе, четыре большие державы и 2–3 малые, 40–60 провинций, 15–25 городов.

## 1. Настройки генератора
1. Открыть https://azgaar.github.io/Fantasy-Map-Generator/.
2. Меню (стрелка ◄ слева вверху) → вкладка **Options** → блок **Map settings**. Выставить:

   | Настройка | Значение | Зачем |
   |---|---|---|
   | Map size | 1600 × 900 px | вытянутый регион |
   | Points number | 10K | рекомендованное значение, хватает на 50 провинций |
   | Heightmap | Mediterranean | море посередине, суша вокруг |
   | Cultures set | European | европейские и турецкие имена |
   | Cultures number | 8 | 4 больших державы, малые и общины |
   | States number | 7 | 4 большие + 3 малые |
   | Provinces ratio | 40 | 40 % бургов станут центрами провинций |
   | Size variety | 4 | большие и маленькие державы рядом |
   | Growth rate | 1.5 | почти без ничейной земли |
   | Burgs number | 120 | бургов нужно больше, чем провинций |
   | Religions number | 4 | разные веры для общин Измары |

3. У каждой изменённой настройки замок слева должен быть **закрыт**. Открытый замок значит, что при новой карте значение выпадет случайно.
4. Меню → вкладка **Tools** → **Units**. Distance unit: **Kilometer**, «1 map pixel» = **1.25**. Регион станет около 2000 × 1100 км.

## 2. Выбрать карту
Кнопка **New Map** (или F2), пока не получится:
- внутреннее море в середине и узкий пролив, который выходит к краю карты или открытой воде на **западе**. Если пролив вышел на восток, карту можно отразить мысленно: просто поменяйте стороны в шаге 3;
- суша с трёх сторон моря, на севере и юге её достаточно для больших держав;
- нет большого количества островов.

Понравившуюся карту лучше сразу сохранить (шаг 5, только `.map`), чтобы не потерять.

## 3. Расставить державы
Меню → **Tools** → **States** (редактор держав).
1. Выбрать четыре самые крупные державы и поставить их по схеме:
   - **Free Provinces of Haverland** — северо-западное побережье океана у входа в пролив; форма — Republic;
   - **Kingdom of Aurenne** — запад и юго-запад, самая большая суша; форма — Kingdom;
   - **Borean Empire** — север и северо-восток, с узким выходом к морю на северном берегу; форма — Empire;
   - **Sultanate of Izmara** — южный и восточный берега моря и оба берега пролива; форма — Sultanate.
2. Переименовать их (имя и форма правления в редакторе). Три оставшиеся — малые державы: имена из Azgaar, можно поправить.
3. Границы подвинуть кистью «Manually re-assign states» (иконка кисти в редакторе держав).
4. Столицы: в **Tools → Burgs** найти столицу каждой большой державы и переименовать: Haverland — **Ostmere** (должна быть портом), Aurenne — **Valmont**, Borea — **Novomor** (порт на море), Izmara — **Sarayhan** (на проливе, порт). Если столица стоит не там — сделать столицей другой бург (в редакторе бурга). Для Бореи найти внутренний город и назвать его **Kostrograd** — это старая столица.

## 4. Имена, провинции, города, моря
1. **Культуры имён.** Меню → **Tools** → **Cultures**. Каждой культуре назначить базу имён (Namesbase): культура Хаверланда — German, Оренна — French, Бореи — Ruthenian, Измары — Turkish, ещё две культуры на землях Измары — Greek и Levantine, малых держав — Italian, Hungarian, Mongolian.
2. **Пересоздать имена.** **Tools → Regenerate → Burgs**: бурги и дороги создадутся заново с именами по культурам, державы останутся. После этого — **Tools → Regenerate → Provinces**. Переименованные вручную столицы проверить ещё раз (шаг 3.4).
3. **Провинции.** **Tools → Provinces**: внизу виден общий счёт. Нужно 40–60. Меньше — поднять Provinces ratio и снова Regenerate → Provinces; больше — опустить. Имена провинций поправить по вкусу.
4. **Города.** **Tools → Burgs**: города игры — бурги групп `capital` и `city`. Нужно 15–25. Если меньше — перевести крупные бурги в группу `city` в редакторе бурга, если больше — наоборот.
5. **Морские зоны.** **Tools → Zones** → добавить 3–6 зон и закрасить кистью воду (галочку «land only» снять). Например: Western Ocean, The Strait, Inner Sea (west), Inner Sea (east). Каждую каплю моря у берегов нужно отнести к какой-то зоне.
6. **Ничейная земля.** Мелкие клочки без державы не страшны: импорт присоединит их к соседям. Большие ничейные куски лучше отдать соседней державе кистью из шага 3.3.

## 5. Сохранить и экспортировать
Все три файла — из одного и того же состояния карты, сразу друг за другом:
1. **Save → machine** — файл `.map`. Переименовать в `region.map`.
2. **Export → Export To JSON → full** — файл `.json`. Переименовать в `region.json`.
3. **Export → Download image → .svg** — переименовать в `region.svg`.

## 6. Передать файлы в репозиторий
Через GitHub в браузере:
1. Открыть https://github.com/timopheus/dynasty-sim, переключиться на ветку задачи (кнопка выбора ветки над списком файлов; имя ветки — в PR «[1.6] Карта и державы»).
2. Зайти в папку `map`, нажать **Add file → Upload files** и перетащить три файла.
3. **Commit changes** прямо в ветку задачи (не в main).
4. Написать в чат сессии, что файлы загружены.

Лимит GitHub для загрузки через браузер — 25 МБ на файл. Если `region.json` больше, скажите в чате: его можно сжать в `.zip` или прислать другим способом.

## Потом: как править карту
Открыть `map/region.map` через **Load**, поправить, затем повторить шаги 5–6. Игра берёт карту только из этих файлов (D-025).
