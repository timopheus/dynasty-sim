# Эталонный человек: план и журнал расходов

Решение Тима 24.10: один человек, по одной генерации с разбором после каждой; бюджет — $10,02 и больше не будет. Каждую генерацию Тим согласует заранее.

## Рамка, а не референс
- Во вход генерации **ничего не подаётся** (ни шаблон, ни прошлые портреты): img2img копирует форму входа, а нам нужна только рамка.
- Рамка — числа, которые проверяет `tools/portrait/frame_check.py` (бесплатно, без сети):
  - фон прозрачный (`remove_bg`, цена не меняется) — силуэт отделён от фона точно; фон подставляет игра;
  - палитра 100 % из 10 ступеней;
  - середина головы x = 32 ± 1 (после сдвига на целые пиксели);
  - макушка y = 8…12, ширина головы 26…36 (полнота, пол и гены дают разную форму — это допуск, а не одна форма);
  - перекос плеч (разница высоты левого и правого плеча) не больше 2 px;
  - линия глаз y = 31 ± 1 (проверка глазами на 6×, позже — автоматически).
- Сдвиг выравнивания — только на целые пиксели; масштабирование пиксель-арта запрещено.
