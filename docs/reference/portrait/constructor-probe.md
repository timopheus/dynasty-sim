# Проба конструктора по модели Papers Please

Решение Тима 24.10: эталон «один человек — перерисовки по маске» не даёт библиотеки (каждая деталь подходит только своему лицу, платить пришлось бы за каждого человека). Берём модель Papers Please: детали рисуются один раз, код собирает из них любое лицо; рисует RD вместо художника.

## Что переносится из эталона
Рамка в числах, палитра и свет, прозрачный фон и зелёный ключ, проверки (вне маски 0 изменений, палитра, чистка, смягчение), маски зон лица — будущие слоты, код оспин и анимации ожидания.

## Устройство
- **Манекен** — одна стандартная голова на пол и возраст (для пробы — `base.png`, мужчина ~35). Все детали рисуются на нём и садятся по его опорным точкам.
- **Слоты:** форма головы (контур лица, щёки, челюсть — кожа вокруг черт), глаза с бровями, нос, рот; позже уши, причёска с убором (I-021), борода, одежда, следы, наборы мимики (рот и брови «гнев», «радость»… общие для всех).
- **Деталь** = зона слота, вырезанная по маске. Тона кожи хранятся как сдвиг ступени от тона кожи манекена, поэтому деталь перекрашивается под любую кожу кодом (I-022).
- **Дешёвый способ:** генерация RD Fast по манекену (img2img, $0,03) — из одной картинки вырезаются сразу все слоты; остальное выбрасывается. Перерисовка по маске ($0,18) — только где img2img не справится.
- **Сдвиг в рамке** (идея Тима): при показе портрет случайно сдвигается на ±2–3 px по вертикали и ±1–2 px по горизонтали от сида человека; рамка генерации остаётся строгой.

## Проба (потолок $0,40)
1. Калибровка ($0,03): одна генерация по манекену, сила 0,45, запрос «другой человек: круглое полное лицо, маленькие широко посаженные глаза, широкий нос, тонкие губы». Проверка: черты стоят на своих точках (линия глаз, нос, рот ±1 px), а внешность изменилась заметно. Если нет — сила 0,35 или 0,6.
2. Ещё 3 генерации ($0,09) с разными описаниями (вытянутое лицо, тяжёлая челюсть, арабские черты; узкое лицо; широкое скуластое).
3. Бесплатно: вырезать слоты, привести кожу к сдвигам ступени, собрать кодом 12 лиц из случайных сочетаний (5 вариантов каждого слота = 625 сочетаний) со случайным сдвигом в рамке; проверить швы.
Итог пробы: лист 12 лиц, цена детали, список швов и что править.
