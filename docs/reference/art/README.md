## Шрифты
- Текст — PT Serif 14 px (кириллица и латиница).
- Имена, даты, заголовки окон и разделов — Cormorant Garamond 600–700.
- Оба — Google Fonts, свободные лицензии (OFL); при сборке — свои копии в проекте, без внешних запросов.

## Рамки и текстуры
- Сейчас — CSS: двойная рамка (внешняя бронза, тёмный зазор, внутренняя тонкая), тень 0 8px 22px.
- В ART.1 — растровые рамки «9-slice» (углы с орнаментом) и лёгкая фактура дерева или кожи на панелях; герб — щит с рамкой. Сгенерированные ассеты — с журналом происхождения (`docs/reference/art/provenance.md`, D-430).

## Карта
Яркая на тёмных панелях: держава — крупной разрядкой, город — точкой с ореолом, подпись с ореолом пергамента. WebGL — ART.2.
