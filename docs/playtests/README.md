# Журнал плейтестов

Здесь живут отзывы Тима о сборках (D-430). Один плейтест — один файл `ГГГГ-ММ-ДД.md` по шаблону ниже. Ведущая сессия превращает каждый отзыв в проверяемый критерий, правку эталона или идею в IDEAS и отмечает это в разделе «Что сделано по отзыву».

Отзыв в чате не теряется: ведущая сессия переносит его сюда сама.

## Шаблон

```
# Плейтест ГГГГ-ММ-ДД

Сборка: <ссылка и версия>. Seed: <число>. Сколько играл: <минут>.

## 1. История
Что случилось в партии — так, как пересказал бы другу.

## 2. Скука и непонимание
Где было скучно, однообразно, непонятно, что делать или почему так вышло.

## 3. Понравилось
Моменты, которые хочется повторить.

## 4. Идеи
Что хочется добавить или изменить. Идеи идут в IDEAS и напрямую не исполняются.

## Что сделано по отзыву (заполняет ведущая сессия)
- пункт → критерий задачи / правка эталона / идея I-…
```
