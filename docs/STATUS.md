# Состояние проекта

Обновлено: 2026-10-15, задача 1.1.

## Сейчас
Этап 1 «Концепт и опоры». Задача 1.1 (каркас репозитория) готова. Следующие — дизайн-задачи 1.2–1.6.

## Что работает
- Игра в браузере (`npm run dev`): один герой, 5 действий, 13 событий, хроника на экране. `?seed=N` фиксирует историю.
- Прогон без интерфейса (`npm run sim -- --years 300 --seed N`): бот выбирает случайно, хроника пишется в `out/`. Пример, seed 42: 300 лет, 16 глав рода, около 1200 событий, нарушений нет.
- Проверки: `npm run typecheck`, `npm test` (35 тестов), `npm run validate`. CI запускает их на каждый PR вместе с прогоном на 50 лет; хроника прикладывается к результату.
- Сохранение — `JSON.stringify` состояния; загрузка продолжает ту же историю. В интерфейсе кнопок сохранения пока нет.

## Заглушки и ограничения
- Наследник — временный: взрослый с той же фамилией, получает только деньги (D-007, до этапа 4).
- События без условий, кроме привязки к действию; последствия фиксированы, без продолжений и ролей.
- Рассказчик — только постоянный шанс события и паузы между событиями.
- У персонажей нет характеристик, черт, пола и отношений, поэтому в текстах нет местоимений.
- Деньги ничем не ограничены и к 300 годам копятся до десятков тысяч: экономики пока нет.
- Мира, карты и держав нет.
